小三度上行結構

Posted on 2025-09-05 Edited on 2025-09-11

本篇難度：★★☆ ～ ★★★☆

動機

我們先來回憶兩個251家族的進行。

  1. F-G-C (451)

  2. Ab-Bb-C (b6-b7-1)（也就是瑪利歐終止）

接著我們把這兩個進行合在一起。

F-G-Ab-Bb-C

因為前述的251家族，F-G 有接到 C 的傾向(451)，也可能依據第二條(b6-b7-1)而有接到 A 的傾向。但接下來不是接到 C 也不是接到 A，反而是把這兩個和弦「移高小三度」再堆疊一次。 是不是有一種「不斷上升」的感覺呢。我們也可以多加一個低三度的根音，變成：

Dm7-Em7-Fm7-Gm7-C

例：Mario Odessey Trailer Theme

（其實這裡的3是C/E，但不影響整體結構）

這裡變成了23451（ii-iii-iv-v-I）。注意到ii-iii和IV-V一樣可以提供「由橋到外面」，且上行的感覺。

在這兩個例子中，都是前兩個和弦在「移高小三度」後，變成了第三第四個和弦。

...那我們是不是可以再多堆幾次呢。

核心架構

  1. うまぴょい伝説（intro）

如果完全對稱的話，第二個和弦應該會是C，但這裡使用了Cm。一方面也是為了配合原調Bb大調的調內和弦ii。這段音樂中就從Bb大調轉到了B大調！

在小三度堆疊的同時，也附帶了轉調意圖。最後的 G-A-B 正是 B大調的 b6-b7-1。

在聽的過程，其實完全無法預測最後會上升到什麼地方。我們可以不斷的進行小三度堆疊，也不會有任何不順的感覺（只是要注意音域啦）

我們可以來比較以下幾個版本。

我們也可以在最後改成普通的251。

  1. 瀬名航 - ショウタイム×オーディエンス

這段從主歌的C大調轉到了A大調。透過小三度上行經過了三個調的ii-iii，最後用A大調的251收尾。旋律部分則分別是和弦的9度音與7度音，也形成一個鋸齒的結構（上下上下，整體往上）

這個段落是第二次主歌接副歌處。也可以參考這首歌的第一次主歌接副歌處，比較一下兩者有何異同吧。

  1. cookie197 - 明日への翼

和上個很接近喔。

  1. 田中秀和 - precious

最後最特別的例子：這次的小結構不再是2-3或4-5的上行，而是4-3-2下行。我們從Eb大調4-3-2，往上小三度經過Gb大調4-3-2和A大調的4-3-2-5，再透過旋律上半音絲滑的進入Bb9sus，也是原調Eb大調的5級。 在小三度上行結構中，旋律都是和弦的7度音，所以就形成一種平行移動（方向都向下）的感覺。

其他類似想法

  • 初音黏土人？

Em7 - F#m7 - Gm7 - C - D

ii-iii-iv-bVII-I。可以說是上面「動機」那一塊的變體，融合了451和b6-b7-1。記得iv-bVII-I也稱為「backdoor 251」，在251家族中有提及！

  • 久石讓 - Osono's Request

注意到第一句和第二句不僅和弦平移（都只是簡單的251），連旋律都是完全的向上平移小三度。「同樣的東西但變高一點」光是這點就能感覺到張力的提升。

如果用轉調的概念解釋，這其實就是簡單的±3轉調，在大多數情形下±3的直接轉都會很順。如果繼續堆疊會怎麼樣呢..？

  • Casiopea - beyond the galaxy

G - A/G - Bb/G - C/G (loop)

固定根音下，高音部的前兩個和弦經過小三度上移後變成後兩個和弦。G-A 是D大調 4-5 的感覺，Bb-C 則是F大調 4-5 的感覺。

延伸

講到小三度，就讓人聯想到「減音階」（又稱全半/半全音階）了。無論是在爵士或20世紀古典都是常見的結構之一，這就未來有機會再說吧。

變化屬和弦、減結構、印象派、有限移位調式..
